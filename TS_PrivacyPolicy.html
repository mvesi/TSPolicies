Privacy Policy

Last Updated: May 2026

This Privacy Policy explains how the ACI Event Group Transaction Sync Integration Tool ("we," "our," or "the Service") collects, uses, and secures financial and personal information when interacting with the QuickBooks Online API.

1. Information We Collect via Intuit API

When connecting to QuickBooks Online, the Service securely accesses:

  • OAuth Credentials: Client IDs, Client Secrets, Access Tokens, and Refresh Tokens.

  • Financial Data: Transaction records, invoices, bank feeds, expenses, and ledger entries necessary to complete your automated data import workflows.

2. Data Storage & Hosting (Data at Rest)

  • Local Hosting: All financial data pulled from or pushed to QuickBooks Online is processed locally on your machine or private network.

  • Encryption: Intuit OAuth credentials and tokens are encrypted at rest using industry-standard encryption protocols (AES-256) and are stored securely in environment variables or isolated local config files.

  • No Third-Party Sharing: We do not sell, rent, or lease financial data or credentials to third parties. Data is transmitted strictly between your local hosting environment and Intuit's secure API endpoints.

3. Data Retention & Deletion

Access tokens expire after a set time defined by Intuit. Refresh tokens rotate dynamically. If you disconnect the app, all session tokens are immediately wiped from local memory. You can request a complete purge of localized cache files at any time.

4. Security Measures

We employ rigorous physical, electronic, and managerial protections to prevent unauthorized access to the local hosting machine. This includes requiring secure HTTPS callback URLs (via encrypted tunnels like ngrok during deployment phases) to prevent token interception.

5. Changes to This Policy

We will update this policy as necessary to remain compliant with the Intuit Developer Data Security standards.
